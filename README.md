# 💳 Credit-Wise: Loan Approval Prediction System

## 📌 Project Overview

Credit-Wise is a Machine Learning mini-project that predicts whether a loan application will be approved or rejected based on applicant information.

The project uses three supervised machine learning classification algorithms and compares their performance to identify the best-performing model.

## 🎯 Objectives

- Predict loan approval status using Machine Learning.
- Implement Logistic Regression, KNN, and Gaussian Naive Bayes.
- Compare model performance using evaluation metrics.
- Identify the best-performing classification algorithm.

## 🤖 Machine Learning Algorithms

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes

## 📊 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🚀 How to Run

1. Clone the repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run all cells to train and evaluate the models.

## 📈 Model Comparison

The models are evaluated using accuracy, precision, recall, and F1-score.

The best-performing model is selected based on the evaluation results.
